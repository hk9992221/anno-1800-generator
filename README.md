# Anno 1800 卡牌工坊

为《纪元 1800》制作自己的专家和物品卡牌。选择头像、指定工厂，用效果积木组合生产率、劳动力、额外产出和原料替换，再把多张卡牌导出为同一个 Mod。

**[下载 Windows 版 →](https://github.com/hk9992221/anno-1800-generator/releases/latest)**

| 版本         | 适合谁                           | 使用方式                                        |
| ------------ | -------------------------------- | ----------------------------------------------- |
| **Setup**    | 希望有开始菜单入口的用户         | 运行安装程序，按提示安装                        |
| **Portable** | 希望解压即用、随文件夹移动的用户 | 解压 ZIP 后打开程序，保留旁边的 `portable.flag` |

支持 Windows 10 / 11（64 位）。便携版需要系统已安装 Microsoft Edge WebView2；安装版会引导准备运行环境。

## 可以做什么

- 自定义卡牌名称、背景、稀有度、安装位置和价格。
- 上传图片并裁剪，或从本机游戏资源中选择已有头像。
- 按世界筛选、多选适用建筑；选择器分页浏览，可全选筛选结果。
- 读取本机原版、DLC 与已安装 Mod 的具体资产定义，识别继承的生产建筑和商品。
- 制作市政厅卡牌，多选居民阶级；配置幸福度、税收、商品消耗，以及“满足 X 后自动满足多个 Y”。
- 调整农田模块、电力、吸引力及建筑已有的污染／噪音影响。
- 制作船舶和飞艇卡牌，组合航速、货物减速抵消、装卸、维护费、耐久与战斗效果。
- 按商人和解锁阶段自动选择对应物品池，或设置壮丽艺廊获取途径。
- 编写任务名称、说明、目标、出现条件和卡牌奖励；配置远征任务、事件、选项与物资要求。
- 复制卡牌、批量生成变体、批量修改选定字段。
- 导入已有 Mod 的卡牌，或编辑原 Mod 的独立副本。
- 保存工程，反复修改后更新固定名称的 Mod。
- 导出前检查引用和配置，预览文件变更，保留上一次输出备份。

## 开始制作

1. 打开“本机资源库”，选择包含 `maindata` 和 `Bin` 的 Anno 1800 游戏根目录。软件自动读取资源，并检查游戏目录和 Windows 文档中的已安装 Mod。位置会被记住，后续扫描无需重复找文件夹。
2. 等待“游戏资源读取结果”显示归档、建筑、商品和中文文本数量，查看有无读取失败。扫描结束会留在结果页。新建卡牌，填写名称；需要头像时，在“图片与头像”点击“浏览游戏头像”，或上传自己的图片。
3. 在“效果积木”中添加需要的效果，在“获取途径”中设置来源。
4. 保存工程，检查卡牌预览和校验结果。小窗口可点击“卡牌预览”打开独立预览。
5. 导出 ZIP，或选择游戏的 `mods` 目录更新 Mod。重新启动游戏后查看卡牌。

资源名称优先使用游戏的简体中文文本；未读取游戏时也有常用工厂和商品的中文参考。建筑按建造地区筛选，商品按生产来源筛选，多地区商品可在相应世界中找到。旧世界与崔老妮海角共用温带建筑配置，会合并显示；没有确认地区的资源单独标明。

`data0.rda`、`data1.rda` 等是游戏自带的资源归档，软件会依次扫描并使用更新后的内容。独立场景资源单独处理；普通选择器默认隐藏内部资源池与场景专用内容，只列出可理解的建筑和商品。建筑组合和手动物品池保留在高级入口中。

商人包括老奈特、亚奇博德、伊莱、卡希纳、尚、安、库马克等，读取本机游戏后还会识别其他交易档案。老奈特的北极档案会继承共用交易池。切换商人或解锁阶段会自动更新获取池；不同档案可能共用同一池。未确认卡牌交易池的商人会明确标注，读取游戏后以实际配置为准。手填 GUID 收在高级入口中。

点击待处理问题可直接进入相应的图片、目标、效果或获取途径页面。XML 无法按 UTF-8 读取时会自动尝试 GBK，兼容没有编码声明的旧 Mod；两种编码都失败时会报告来源，不用替换字符冒充完整读取。失败项目在“本机资源”的读取结果和提示中显示。

效果积木、批量递进等数字框允许先输入负号、再输入数字；清空或仅输入负号时不会立即变成 0。

“池内相对权重”是同一池中各条目的抽取权重，编辑范围为 1–1,000,000 的整数。例如池内只有权重 100 和 200 两项时，单次抽取约为 1/3 和 2/3；它不是最终获得概率，多层池、条件和多次抽取会改变结果。

“工会”用于生产建筑，“市政厅”用于住宅。“卡组”只整理列表，不决定效果。市政厅应先多选居民阶级，再选择需求；选择器会显示需求适用的阶级，校验会提醒不匹配的组合。

一张卡牌的所有效果共同作用于所选目标。原料替换只影响实际消耗该原料的工厂；物品池也可能被多个商人或奖励系统共享，选择时请核对来源。

船舶卡牌作用于装备它的船，适用船型由安装位置决定。额外装备插槽与普通货物舱位分别计算。

## 继续编辑和分享

保存的工程包含卡牌和上传图片，移动工程文件后仍可继续编辑。本工具生成的 Mod 也包含可重新打开的工程信息。

新卡牌的编辑 ID 使用“本机日期时间 + 序列 + 随机数”，同时分配并保存游戏使用的数字 GUID。改名、调整效果和重复导出会保留原有身份。已发布卡牌可选择“仅停止获取”，保留存档中已有物品的定义；也可以确认删除，让下次导出移除卡牌。删除可以撤销，已分配的 GUID 不会复用。删除已经存在于存档中的物品可能导致它丢失。

读取外部 Mod 时，可以复制支持的卡牌加入自己的合集，或创建保留原 GUID 的编辑副本。未知配置会显示编辑限制并保留原文。

## 数据位置

安装版将草稿、资源缓存和输出备份保存在本机应用数据目录。便携版保存在程序旁的 `CardForgeData` 中。

原版头像和资源来自用户本机游戏，不包含在软件中。不支持的 RDA 格式会提示改选已解包的资源目录；复杂 XPath 补丁和脚本不会被当作已解析的具体资产。

远征途径生成一次性特殊远征：满足条件后开放，事件选项成功后取得卡牌；有物资要求时提供无奖励的绕行选项。任务奖励支持库存、建筑、人口等持续目标和重复次数。远征、任务、壮丽艺廊交付和卡牌效果仍需在对应的游戏、DLC 与存档环境中验证。
