# Anno 1800 卡牌工坊

为《纪元 1800》制作自己的专家和物品卡牌。选择头像、指定工厂，用效果积木组合生产率、劳动力、额外产出和原料替换，再把多张卡牌导出为同一个 Mod。

**[下载 Windows 版 →](https://github.com/hk9992221/anno-1800-generator/releases/latest)**

| 版本 | 适合谁 | 使用方式 |
| --- | --- | --- |
| **Setup** | 希望有开始菜单入口的用户 | 运行安装程序，按提示安装 |
| **Portable** | 希望解压即用、随文件夹移动的用户 | 解压 ZIP 后打开程序，保留旁边的 `portable.flag` |

支持 Windows 10 / 11（64 位）。便携版需要系统已安装 Microsoft Edge WebView2；安装版会引导准备运行环境。

## 可以做什么

- 自定义卡牌名称、背景、稀有度、安装位置和价格。
- 上传图片并裁剪，或从本机游戏资源中选择已有头像。
- 多选适用建筑，用积木组合多个效果。
- 添加指定商人物品池和壮丽艺廊获取途径。
- 复制卡牌、批量生成变体、批量修改选定字段。
- 导入已有 Mod 的卡牌，或编辑原 Mod 的独立副本。
- 保存工程，反复修改后更新固定名称的 Mod。
- 导出前检查引用和配置，预览文件变更，保留上一次输出备份。

## 开始制作

1. 打开“本机资源库”，选择游戏安装目录或已经解包的资源目录。完成索引后，可搜索建筑、商品、头像和物品池。
2. 新建卡牌，填写名称，选择安装位置和适用目标。
3. 在“效果积木”中添加需要的效果，在“获取途径”中设置来源。
4. 保存工程，检查右侧卡牌预览和校验结果。
5. 导出 ZIP，或选择游戏的 `mods` 目录更新 Mod。重新启动游戏后查看卡牌。

一张卡牌的所有效果共同作用于所选目标。原料替换只影响实际消耗该原料的工厂；物品池也可能被多个商人或奖励系统共享，选择时请核对来源。

## 继续编辑和分享

保存的工程包含卡牌和上传图片，移动工程文件后仍可继续编辑。本工具生成的 Mod 也包含可重新打开的工程信息。

新卡牌的编辑 ID 使用“本机日期时间 + 序列 + 随机数”，同时分配并保存游戏使用的数字 GUID。改名、调整效果和重复导出会保留原有身份。已发布卡牌可以“停止获取”，保留存档中已有物品的定义。

读取外部 Mod 时，可以复制支持的卡牌加入自己的合集，或创建保留原 GUID 的编辑副本。未知配置会显示编辑限制并保留原文。

## 数据位置

安装版将草稿、资源缓存和输出备份保存在本机应用数据目录。便携版保存在程序旁的 `CardForgeData` 中。

原版头像和资源来自用户本机游戏，不包含在软件中。RDA 的不支持格式会提示使用已解包资源入口。壮丽艺廊导出的购买、帕洛玛交付及卡牌实际效果需要在对应游戏环境中验证。

## 反馈

遇到问题，可以在 [Issues](https://github.com/hk9992221/anno-1800-generator/issues) 提供软件版本、卡牌类型、操作步骤和错误提示。分享 Mod 前请确认资源来源及 GUID 的使用范围。
